`criteo_sample.tsv.gz` holds every impression of 1,275 users (uid % 5000 = 17) from the
Criteo Attribution Modeling for Bidding Dataset: 3,299 impressions and 80 conversions across days 0 to 30.
It is used by the tests and by CI so they run without the full 653 MB download.

Source: Criteo AI Lab, https://huggingface.co/datasets/criteo/criteo-attribution-dataset
Licence: CC BY-NC-SA 4.0. Paper: Diemert, Meynet, Galland, Lefortier, "Attribution Modeling
Increases Efficiency of Bidding in Display Advertising", AdKDD & TargetAd Workshop, KDD 2017.
